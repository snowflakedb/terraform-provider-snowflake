# snowflake_replication_group (Resource)

Resource used to manage replication groups in the source account. For more information, check [replication group documentation](https://docs.snowflake.com/en/sql-reference/sql/create-replication-group).

## Example Usage

-> **Note** Instead of using fully_qualified_name, you can reference objects managed outside Terraform by constructing a correct ID, consult [identifiers guide](../guides/identifiers_rework_design_decisions#new-computed-fully-qualified-name-field-in-resources).
<!-- TODO(SNOW-1634854): include an example showing both methods-->

```terraform
## Minimal
resource "snowflake_replication_group" "basic" {
  name = "replication_group_name"
  object_types = [
    "DATABASES",
  ]
  allowed_accounts = [
    "\"<organization_name>\".\"<account_name>\"",
  ]
  allowed_databases = [
    snowflake_database.example.fully_qualified_name,
  ]
}

## Complete
resource "snowflake_replication_group" "complete" {
  name = "replication_group_name"
  object_types = [
    "DATABASES",
    "ROLES",
    "EXTERNAL VOLUMES",
    "SHARES",
    "INTEGRATIONS",
  ]
  allowed_accounts = [
    "\"<organization_name>\".\"<account_name>\"",
  ]
  allowed_databases = [
    snowflake_database.example.fully_qualified_name,
  ]
  allowed_external_volumes = [
    snowflake_external_volume.example.fully_qualified_name,
  ]
  allowed_shares = [
    snowflake_share.example.fully_qualified_name,
  ]
  allowed_integration_types = [
    "API INTEGRATIONS",
    "EXTERNAL ACCESS INTEGRATIONS",
    "NOTIFICATION INTEGRATIONS",
    "SECURITY INTEGRATIONS",
    "STORAGE INTEGRATIONS",
  ]
  ignore_edition_check = "true"
  replication_schedule = "10 MINUTE"
  error_integration    = snowflake_notification_integration.example.fully_qualified_name
  comment              = "My replication group"
}
```

-> **Note** When this replication group is no longer primary, Terraform recreates it as a primary group. Moving the object to [`snowflake_replication_group_secondary`](./replication_group_secondary) is a manual state migration. See [resource migration](../guides/resource_migration).

-> **Note** If a field has a default value, it is shown next to the type in the schema.

## Schema

### Required

- `allowed_accounts` (Set of String) Target accounts, as organization and account name, to which replication is enabled. Snowflake also includes the source account.
- `name` (String) Specifies the identifier for the replication group; must be unique for the account. Due to technical limitations (read more [here](../guides/identifiers_rework_design_decisions#known-limitations-and-identifier-recommendations)), avoid using the following characters: `|`, `.`, `"`.
- `object_types` (List of String) Types of objects replicated from the source account to the target accounts. Valid values are (case-insensitive): `ACCOUNT PARAMETERS` | `DATABASES` | `EXTERNAL VOLUMES` | `INTEGRATIONS` | `NETWORK POLICIES` | `RESOURCE MONITORS` | `ROLES` | `SHARES` | `USERS` | `WAREHOUSES`.

### Optional

- `allowed_databases` (List of String) Databases enabled for replication. OBJECT_TYPES must include DATABASES.
- `allowed_external_volumes` (List of String) External volumes enabled for replication. Preview feature, open to all accounts. OBJECT_TYPES must include EXTERNAL VOLUMES.
- `allowed_integration_types` (List of String) Integration types enabled for replication. Requires Business Critical Edition or higher. OBJECT_TYPES must include INTEGRATIONS. SECURITY INTEGRATIONS also requires ROLES. Valid values are (case-insensitive): `SECURITY INTEGRATIONS` | `API INTEGRATIONS` | `STORAGE INTEGRATIONS` | `EXTERNAL ACCESS INTEGRATIONS` | `NOTIFICATION INTEGRATIONS`.
- `allowed_shares` (List of String) Shares enabled for replication. OBJECT_TYPES must include SHARES.
- `comment` (String) Comment for the replication group. The alter page defaults it to NULL. CREATE has no COMMENT clause.
- `error_integration` (String) Notification integration that receives refresh error notifications.
- `ignore_edition_check` (String) (Default: fallback to Snowflake default - uses special value that cannot be set in the configuration manually (`default`)) Allows replication to accounts on lower editions in the cases listed on the create page. Available options are: "true" or "false". When the value is not set in the configuration the provider will put "default" there which means to use the Snowflake default for this value.
- `replication_schedule` (String) Schedule for refreshing secondary replication groups. An interval (`<num> MINUTE`) or `USING CRON <expr> <time_zone>`. NULL when unset.
- `timeouts` (Block, Optional) (see [below for nested schema](#nestedblock--timeouts))

### Read-Only

- `fully_qualified_name` (String) Fully qualified name of the resource. For more information, see [object name resolution](https://docs.snowflake.com/en/sql-reference/name-resolution).
- `id` (String) The ID of this resource.
- `is_primary` (Boolean) Indicates if the replication group is primary. When Terraform detects that the primary status changed outside of Terraform, the resource is recreated.
- `show_output` (List of Object) Outputs the result of `SHOW REPLICATION GROUPS` for the given replication group. (see [below for nested schema](#nestedatt--show_output))
