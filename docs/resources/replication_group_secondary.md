# snowflake_replication_group_secondary (Resource)

Resource used to manage a replication group replica in the target account. For more information, check [replication group documentation](https://docs.snowflake.com/en/sql-reference/sql/create-replication-group).

## Example Usage

-> **Note** Instead of using fully_qualified_name, you can reference objects managed outside Terraform by constructing a correct ID, consult [identifiers guide](../guides/identifiers_rework_design_decisions#new-computed-fully-qualified-name-field-in-resources).
<!-- TODO(SNOW-1634854): include an example showing both methods-->

```terraform
resource "snowflake_replication_group_secondary" "basic" {
  name    = "replication_group_name"
  primary = "\"<organization_name>\".\"<account_name>\".\"<replication_group_name>\""
}
```

-> **Note** When this replication group becomes primary, Terraform recreates it as a replica of `primary`. Moving the object to [`snowflake_replication_group`](./replication_group) is a manual state migration. See [resource migration](../guides/resource_migration).

-> **Note** If a field has a default value, it is shown next to the type in the schema.

### Required

- `name` (String) Specifies the identifier for the replication group secondary; must be unique for the account. ### Optional

- `primary` (String) Primary replication group to replicate, as org.account.name. This is the AS REPLICA OF identifier.
