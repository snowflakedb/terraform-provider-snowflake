# snowflake_code_bundle (Resource)

Resource used to manage code bundles. For more information, check [code bundle documentation](https://docs.snowflake.com/en/developer-guide/code-bundles/code-bundles).

## Example Usage

-> **Note** Instead of using fully_qualified_name, you can reference objects managed outside Terraform by constructing a correct ID, consult [identifiers guide](../guides/identifiers_rework_design_decisions#new-computed-fully-qualified-name-field-in-resources).
<!-- TODO(SNOW-1634854): include an example showing both methods-->

```terraform
## Minimal
# from is ForceNew. It is a snow://workspace/... URL, or an internal or temporary stage reference.
resource "snowflake_code_bundle" "basic" {
  database = "database_name"
  schema   = "schema_name"
  name     = "code_bundle_name"
  from     = "@${snowflake_stage.example.fully_qualified_name}"
}

## Complete
resource "snowflake_code_bundle" "complete" {
  database = "database_name"
  schema   = "schema_name"
  name     = "code_bundle_name"
  from     = "@${snowflake_stage.example.fully_qualified_name}"
  comment  = "My code bundle"
}
```

-> **Note** If a field has a default value, it is shown next to the type in the schema.

## Schema

### Required

- `database` (String) The database in which to create the code bundle. Due to technical limitations (read more [here](../guides/identifiers_rework_design_decisions#known-limitations-and-identifier-recommendations)), avoid using the following characters: `|`, `.`, `"`.
- `from` (String) Specifies the source that backs this code bundle: a snow://workspace/... URL, or an internal or temporary stage reference. External stages are not supported.
- `name` (String) Specifies the identifier for the code bundle; must be unique for the schema in which the code bundle is created. Due to technical limitations (read more [here](../guides/identifiers_rework_design_decisions#known-limitations-and-identifier-recommendations)), avoid using the following characters: `|`, `.`, `"`.
- `schema` (String) The schema in which to create the code bundle. Due to technical limitations (read more [here](../guides/identifiers_rework_design_decisions#known-limitations-and-identifier-recommendations)), avoid using the following characters: `|`, `.`, `"`.

### Optional

- `comment` (String) Specifies a comment for the code bundle.
- `timeouts` (Block, Optional) (see [below for nested schema](#nestedblock--timeouts))

### Read-Only

- `describe_output` (List of Object) Outputs the result of `DESCRIBE CODE BUNDLE` for the given code bundle. (see [below for nested schema](#nestedatt--describe_output))
- `fully_qualified_name` (String) Fully qualified name of the resource. For more information, see [object name resolution](https://docs.snowflake.com/en/sql-reference/name-resolution).
- `id` (String) The ID of this resource.
- `show_output` (List of Object) Outputs the result of `SHOW CODE BUNDLES` for the given code bundle. (see [below for nested schema](#nestedatt--show_output))
