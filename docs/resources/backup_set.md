# snowflake_backup_set (Resource)

Resource used to manage backup sets. For more information, check [backup set documentation](https://docs.snowflake.com/en/user-guide/backups).

## Example Usage

-> **Note** Instead of using fully_qualified_name, you can reference objects managed outside Terraform by constructing a correct ID, consult [identifiers guide](../guides/identifiers_rework_design_decisions#new-computed-fully-qualified-name-field-in-resources).
<!-- TODO(SNOW-1634854): include an example showing both methods-->

```terraform
## Minimal
# Exactly one of for_table, for_dynamic_table, for_schema, or for_database is required, and it cannot be changed.
resource "snowflake_backup_set" "basic" {
  database  = "database_name"
  schema    = "schema_name"
  name      = "backup_set_name"
  for_table = "\"database_name\".\"schema_name\".\"table_name\""
}

## Complete
# An attached backup policy cannot be removed. It can only be changed to another policy.
resource "snowflake_backup_set" "complete" {
  database      = "database_name"
  schema        = "schema_name"
  name          = "backup_set_name_complete"
  for_schema    = "\"database_name\".\"schema_name\""
  backup_policy = "\"database_name\".\"schema_name\".\"backup_policy_name\""
  comment       = "My backup set"
}
```

-> **Note** If a field has a default value, it is shown next to the type in the schema.

## Schema

### Required

- `database` (String) The database in which to create the backup set. Due to technical limitations (read more [here](../guides/identifiers_rework_design_decisions#known-limitations-and-identifier-recommendations)), avoid using the following characters: `|`, `.`, `"`.
- `name` (String) Specifies the identifier for the backup set; must be unique for the schema in which the backup set is created. Due to technical limitations (read more [here](../guides/identifiers_rework_design_decisions#known-limitations-and-identifier-recommendations)), avoid using the following characters: `|`, `.`, `"`.
- `schema` (String) The schema in which to create the backup set. Due to technical limitations (read more [here](../guides/identifiers_rework_design_decisions#known-limitations-and-identifier-recommendations)), avoid using the following characters: `|`, `.`, `"`.

### Optional

- `backup_policy` (String) Specifies the backup policy for the set. It can be omitted at creation and attached later. FORCE overwrites an existing policy only when that policy has no retention lock. An attached policy cannot be removed.
- `comment` (String) Specifies a comment for the backup set.
- `for_database` (String) Specifies the database this backup set backs up (`FOR DATABASE`). Exactly one of the four targets is set, and the target cannot be changed.
- `for_dynamic_table` (String) Specifies the dynamic table this backup set backs up (`FOR DYNAMIC TABLE`). Exactly one of the four targets is set, and the target cannot be changed.
- `for_schema` (String) Specifies the schema this backup set backs up (`FOR SCHEMA`). Exactly one of the four targets is set, and the target cannot be changed.
- `for_table` (String) Specifies the table this backup set backs up (`FOR TABLE`). Exactly one of the four targets is set, and the target cannot be changed.
- `timeouts` (Block, Optional) (see [below for nested schema](#nestedblock--timeouts))

### Read-Only

- `describe_output` (List of Object) Outputs the result of `DESCRIBE BACKUP SET` for the given backup set. (see [below for nested schema](#nestedatt--describe_output))
- `fully_qualified_name` (String) Fully qualified name of the resource. For more information, see [object name resolution](https://docs.snowflake.com/en/sql-reference/name-resolution).
- `id` (String) The ID of this resource.
- `show_output` (List of Object) Outputs the result of `SHOW BACKUP SETS` for the given backup set. (see [below for nested schema](#nestedatt--show_output))
