# Contributing — detailed guides

This directory contains in-depth documentation for contributors. It supplements the top-level [CONTRIBUTING.md](../CONTRIBUTING.md), which covers the overall process (environment setup, PR workflow, review expectations).
The files here go deeper on specific technical topics — the kind of detail that would make the top-level file too long to scan.

## How to use this directory

Start with [CONTRIBUTING.md](../CONTRIBUTING.md) to understand the process. Then come here when you need the specifics for the area you are working in.
